# NIS new program · 5–6 классы — модуль 1

Основа покрытия: `AKEDA_NIS_Math_Skills_Complete_Syllabus.pdf`, страницы 2–4.
Это отдельная программа; старые программы, назначения и результаты не переносятся.
Следующие модули пока не создаются. Шаблоны авторские, параметризованные; исходные
страницы использованы для исследования типов упражнений и математических методов,
а не для копирования банка чужих заданий. Это не официальный банк экзамена НИШ.

## Правила ответа

- Десятичная: запятая и точка разрешены; `2/5` вместо `0,4` — неверно.
- Несократимая дробь: только `a/b`, положительный знаменатель, сокращение обязательно.
- Смешанное: три поля; ненулевая целая часть, правильная несократимая дробная часть.
- Округление до десятых/сотых: сохранить ровно 1/2 знака (`1,0` / `1,00`).
- Удаление лишних нулей: конечные нули после запятой запрещены.
- Упорядочивание и целые интервала: все числа через `;`, порядок проверяется.
- Двойное неравенство: `a < b < c`, пробелы несущественны.
- Степень: `a^n`, вычисленное значение вместо степени — неверно.
- Обычное вычисление без требуемой формы: эквивалентные точные числовые записи допустимы.
- Пустой/слишком длинный ввод не отправляется; ненулевой ввод неверной формы оценивается
  как неправильный ответ. Ограничение длины — 100 символов, нулевые знаменатели запрещены.

## Безопасность и проверка

Ни ответ, ни `answer_display` не передаются клиенту до завершения попытки.
Тип ответа берётся на сервере из сохранённого задания, а не из данных браузера.
Новый RPC `submit_nis_new_skill_attempt_atomic` доступен только `service_role`.
Он проверяет владельца, назначение ученику, полный состав ответов, блокирует попытку,
валидирует весь набор до записи и завершает его атомарно. Админский предпросмотр
использует тот же RPC, но не записывает освоение ученику. Старый RPC не изменён.

`node scripts/nis-new-module-one-harness.cjs`: 100 попыток каждого навыка, 15 400
задач; все подтипы в каждой попытке; уникальные условия; строгий рендер KaTeX;
проверка формата и ловушек эквивалентности; независимый парсер отображаемой
математики для арифметики, уравнений и переводов. Случайные числа меняются при запуске.
Счётчик независимых проверок также немного меняется из-за дополнительных шаблонов.

Миграция: `supabase/20261009-nis-new-module-one.sql`. Применять один раз после
проверки сборки; повторное создание программы блокируется явной ошибкой.
Ученикам новую программу назначает преподаватель; автоматических назначений нет.
